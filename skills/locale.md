# Handy Reader — локали

## Правило

Пользовательский текст (имя приложения, строки интерфейса) вставлять в **обе локали**:

- `app/src/.../res/values/strings.xml` — английская (дефолт)
- `app/src/.../res/values-ru/strings.xml` — русская

Локаль устройства побеждает дефолт: на устройстве с `ru-RU` строка берётся из `values-ru`; текст только в `values/` пользователь с русской локалью не увидит.
