# Handy Reader — общение с пользователем

## Правило вывода

Выдавать **меньше промежуточных рассуждений** — показывать только **итоговые суждения**.

- Не выводить ход размышлений, перебор вариантов, описание каждого шага.
- Представлять результат: вывод, решение, что сделано и что осталось.
- Если шаг требует объяснения — одна короткая фраза с причиной, не развёрнутый процесс.
- Уточняющие вопросы — только если без них нельзя двигаться.
