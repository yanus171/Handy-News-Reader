# Handy Reader — общение с пользователем

## Правило вывода

- Не выводить промежуточных рассуждений — показывать только итоговые суждения: результат, решение, что сделано и что осталось.
- Не пересказывать ход размышлений и каждый шаг.
- Если шаг требует объяснения — одна короткая фраза с причиной, не развёрнутый процесс.
- Уточняющие вопросы — только если без них нельзя двигаться.

## Правило коммитов

- **НИКОГДА не делать `git commit` без явного разрешения пользователя.** Коммит — только после того, как пользователь сам сказал «закоммить» / «commit» / явно одобрил. Предлагать коммит можно, но не выполнять.
- То же касается `git push` и любых других необратимых git-операций.
